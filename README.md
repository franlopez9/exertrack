# 🏋️‍♂️ FitTracker - App de Entrenamiento en Casa

**FitTracker** es una aplicación web interactiva diseñada para llevar el seguimiento y control de rutinas de entrenamiento en casa. Cuenta con un diseño moderno inspirada en **iOS Liquid Glass / Glassmorphism**, soporte para modo oscuro/claro y herramientas esenciales como temporizadores de descanso y cronómetro por ejercicio.

---

## ✨ Características Principales

- 📱 **Diseño iOS Liquid Glass:** Interfaz limpia con efectos de cristal translúcido, sombras suaves y acentos en verde esmeralda.
- 📋 **Plan de 4 Semanas Precargado:** Incluye el programa adaptativo enfocado en:
  - Espalda alta/baja y corrección postural.
  - Tonificación de pectoral (ginecomastia) y zona cervical/papada.
  - Rutinas diarias de 20 a 30 minutos sin equipo.
- ⏱️ **Temporizador de Descanso Interactivo:** Ajustes rápidos de `30s`, `45s`, `60s` y `90s` con alertas sonoras al finalizar el tiempo.
- ⏱️ **Modo "Entrenar" en Vivo:**
  - Cronómetro en tiempo real para medir el tiempo por ejercicio.
  - Tracker de series (*sets*) con casillas de verificación interactivas.
- 🏷️ **Filtros por Categoría y Semana:** Organiza tus ejercicios por zona (*Postura, Pecho, Espalda, Cuello/Papada, Core*) y por semana activa.
- ✏️ **Gestor de Ejercicios (CRUD):** Agrega, edita o elimina ejercicios personalizados según tus necesidades.
- 💾 **Persistencia de Datos:** Guarda todo tu progreso, historial y configuración en `localStorage` sin requerir registro o base de datos externa.
- 🌙 **Modo Oscuro / Claro:** Alterna entre temas visuales manteniendo el contraste y la legibilidad.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Variables CSS, `backdrop-filter` para glassmorphism y diseño responsivo adaptado a móviles.
- **JavaScript (ES6+):** Manipulación del DOM, lógica de temporización, Web Audio API y almacenamiento local (`localStorage`).
